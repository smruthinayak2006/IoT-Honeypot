Extra Learning:

LISTENING:
A service is waiting for connections.

ESTABLISHED:
An active connection exists.

Example:
192.168.1.10:23

192.168.1.10 = Device IP
23 = Application port

Multiple login attempts may indicate brute-force behavior.
